# Gold Signal Pro — نسخه ۰.۲

نسخه پایه PWA برای نمایش تابلوی قیمت طلا، ارز، سکه و نقره.

## فایل‌ها
- `server.mjs`: سرور Node.js و مسیر API
- `public/index.html`: صفحه اصلی
- `public/style.css`: ظاهر برنامه
- `public/app.js`: بروزرسانی خودکار هر ۳۰ ثانیه
- `public/manifest.json` و `public/sw.js`: نصب‌پذیری PWA
- `.env.example`: نمونه تنظیمات

## اجرا
```bash
npm install
npm start
```
سپس آدرس `http://localhost:8080` را باز کنید.

## وضعیت منابع قیمت
این نسخه عمداً قیمت ساختگی تولید نمی‌کند. مسیر `/api/prices` فعلاً داده خالی و وضعیت منابع را برمی‌گرداند. برای نمایش قیمت واقعی باید API رسمی/مجاز هر منبع، احراز هویت، نمادها و واحدها بررسی و به سرور متصل شوند. وجود صفحه یا نام منبع به معنی اتصال زنده نیست.

## استقرار
این پروژه به سرور Node.js نیاز دارد؛ GitHub فقط محل نگهداری کد است و به‌تنهایی `server.mjs` را اجرا نمی‌کند. متغیر `PORT` توسط میزبان تنظیم می‌شود.
