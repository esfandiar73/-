# Gold Signal Pro — نسخه آزمایشی ۰.۱

وب‌اپلیکیشن PWA فارسی برای پایش قیمت طلا، ارز، سکه و نقره و نمایش سیگنال‌های تحلیلی خرید/فروش.

## امکانات فعلی
- طراحی واکنش‌گرا و قابل نصب روی اندروید به شکل PWA
- درخواست قیمت از سرور هر ۳۰ ثانیه، فقط وقتی صفحه فعال است
- اتصال سروری به تابلو ESTJT و صفحات TGJU
- اتصال اختیاری به API الان‌چند با توکن سرور
- تبدیل نرخ‌های ریالی TGJU به تومان
- میانگین منابع موجود، تشخیص اختلاف غیرعادی و نمایش تعداد منابع
- ذخیره تاریخچه کوتاه‌مدت روی همان دستگاه
- رتبه‌بندی آزمایشی خرید و فروش بعد از جمع‌آوری حداقل ۸ مشاهده
- محاسبه حباب تقریبی سکه با فرض وزن و عیار استاندارد سکه

## نیازمندی‌ها
- Node.js نسخه ۲۰ یا بالاتر
- دسترسی اینترنت از سروری که برنامه روی آن اجرا می‌شود

## اجرای محلی
```bash
npm install
cp .env.example .env
npm start
```
سپس در مرورگر باز کنید:
`http://localhost:8080`

برای نصب روی اندروید، در Chrome آدرس برنامه را باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را بزنید. برای نصب از یک دامنه عمومی، HTTPS لازم است.

## فعال‌سازی الان‌چند
۱. از مستندات رسمی الان‌چند توکن آزمایشی بگیرید: https://alanchand.com/media/api  
۲. توکن را فقط در فایل `.env` سرور وارد کنید:
```env
ALANCHAND_TOKEN=YOUR_TOKEN
```
۳. سرور را دوباره اجرا کنید.

توکن را در `public/app.js` یا HTML قرار ندهید. API الان‌چند از سمت سرور فراخوانی می‌شود. مستندات منتشرشده الان‌چند اعلام می‌کند نرخ‌های ارز، طلا و سکه هر ۵ دقیقه به‌روزرسانی می‌شوند؛ بنابراین درخواست ۳۰ ثانیه‌ای اپ لزوماً به معنی تغییر قیمت منبع در هر ۳۰ ثانیه نیست.

## منطق منابع و میانگین
- ESTJT: انس طلا، طلای ۱۸ عیار، سکه امامی، نیم‌سکه و ربع‌سکه.
- TGJU: انس طلا، دلار، طلای ۱۸ عیار، سکه امامی، نیم‌سکه، ربع‌سکه و گرم نقره ۹۹۹.
- الان‌چند: دلار، انس طلا، طلای ۱۸ عیار و انواع سکه؛ توکن لازم دارد.
- ESTJT در تابلوی فعلی دلار آزاد و قیمت گرم نقره ۹۹۹ را نشان نمی‌دهد. در نتیجه برای این دو مورد میانگین سه‌منبعی وجود ندارد. نقره ۹۹۹ در این نسخه از TGJU دریافت می‌شود.
- نرخ‌های داخلی TGJU در ریال گزارش می‌شوند و سرور آن‌ها را بر ۱۰ تقسیم می‌کند تا تومان نمایش داده شود.
- در صورت اختلاف زیاد منابع، کارت دارایی هشدار اختلاف نشان می‌دهد. داده‌های خام هر منبع در بخش «منابع و وضعیت» قابل بررسی‌اند.

## درباره سیگنال‌ها
سیگنال‌ها در این نسخه الگوریتمی و آزمایشی‌اند و از روند چند دقیقه اخیر، درصد تغییر روزانه و حباب تقریبی سکه امتیاز می‌گیرند. برای جلوگیری از سیگنال ساختگی، تا قبل از جمع‌آوری حداقل ۸ نمونه برای هر دارایی سیگنال صادر نمی‌شود.

این منطق هنوز بک‌تست، بهینه‌سازی یا اعتبارسنجی سرمایه‌گذاری نشده است. امتیاز اطمینان، احتمال سود قطعی نیست. سیگنال‌ها توصیه مالی قطعی نیستند و نباید تنها مبنای خریدوفروش قرار گیرند.

## نکات فنی
- رابط کاربری هر ۳۰ ثانیه `/api/market` را صدا می‌زند.
- کش سمت سرور برای ESTJT و TGJU برابر ۶۰ ثانیه است تا از درخواست بی‌رویه جلوگیری شود.
- کش API الان‌چند ۵ دقیقه است تا با چرخه انتشار داده آن هماهنگ باشد.
- PWA هنگام بسته بودن یا خواب دستگاه نمی‌تواند تضمین کند که هر ۳۰ ثانیه اجرا شود.
- داده‌های تاریخچه نسخه اول در حافظه محلی مرورگر ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت، تاریخچه سیگنال همان دستگاه را پاک می‌کند.
- برای انتشار عمومی، روی سرور HTTPS اجرا شود و دسترسی به `.env` محدود بماند.
